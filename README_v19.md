# StudyVault v19 — Light Liquid Glass + Motion

Änderungen gegenüber v18:
- dunklen Anthrazit-Hintergrund entfernt
- heller Off-White/Light-Blue Hintergrund
- weißes transparentes Liquid Glass
- dunkle Schrift + Sparkassen-Rot als Akzent
- stärkere räumliche Glasschatten
- bestehende Funktionen aus v18 unangetastet

Animationen:
- sichtbarer Fade/Slide beim Screenwechsel
- Initialanimation beim App-Start
- Tap/Press-Feedback auf Buttons, Navigation und Karten
- Ripple in der Bottom-Navigation
- echter Flip-Effekt beim Aufdecken einer Lernkarte
- animierter Wechsel zur nächsten Lernkarte
- pulsierendes Audio-Mikrofon
- animierte Audio-Waveform
- sichtbarer KI-Shimmer
- Success-Pop beim Speichern/Übernehmen
- Modal-Animationen bleiben erhalten

Hinweis: `prefers-reduced-motion` des Geräts kann Animationen absichtlich reduzieren.
